Hunch

Open-source markdown notes for iOS & macOS. Each block is a row. Your notes live as plain .md files in a folder you own — open them in any editor, sync them with iCloud, hand them to an agent.

Source on GitHub Privacy policy

What it is

A native block editor for iOS 26 and macOS 26 — paragraphs, headings, lists, toggles, quotes, code, images, subpages. Cmd+P opens a fuzzy page picker; @-mentions link pages; voice dictation has a Siri Shortcut. Edit mode for one block at a time, nav mode for multi-block selection / move / indent — no hover-floating UI.

The on-disk format ("Clamshell") is a folder of plain markdown plus a small amount of sidecar state — a per-device recovery log, trash, assets. Durable, portable, iCloud-friendly. Drop the folder into Obsidian, grep it, version-control it, hand it to an LLM.

What it isn't

  • Real-time multiplayer collaboration
  • Full databases (relations, formulas, rollups, views)
  • Tables
  • AI features

Privacy policy: github.com/jxe/hunch/PRIVACY.md — Hunch collects nothing, transmits nothing, has no server.
